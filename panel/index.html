🔑 Conectar con GitHub

Este panel guarda los cambios directamente en tu repositorio de GitHub. Para eso necesita una clave de acceso (token) que generas tú mismo, una sola vez. Queda guardada solo en este navegador — nunca se sube al repositorio ni la ve nadie más.

  1. Entra a github.com/settings/personal-access-tokens/new (con tu sesión de GitHub abierta).
  2. En Token name escribe algo como panel-catalogo.
  3. En Repository access elige "Only select repositories" y selecciona cuaderno-caligrafia-infantil (así el token NO tiene acceso a nada más de tu cuenta).
  4. Baja a Permissions → Repository permissions, busca "Contents" y cámbialo a "Read and write".
  5. Clic en "Generate token" al final de la página, y copia el código que empieza con github_pat_... (solo se muestra una vez).
